# Rafi Muhammad Arif — Portfolio Website

Website portofolio pribadi untuk menampilkan proyek, pengalaman, dan keahlian saya sebagai mahasiswa Teknik Informatika yang berfokus pada pengembangan web dan mobile.

## Fitur

- Tampilan responsif untuk desktop dan mobile
- Mode terang dan gelap, pilihan tema tersimpan di browser
- Navigasi dengan smooth scroll antar bagian
- Bagian proyek, pengalaman, tech stack, sertifikasi, dan kontak

## Teknologi

- React 19 dan TypeScript
- Vite
- Tailwind CSS v4 dan CSS kustom

## Menjalankan di komputer sendiri

Prasyarat: Node.js versi 20.19 ke atas atau 22.12 ke atas.

```bash
npm install
npm run dev
```

Lalu buka http://localhost:8080 di browser.

Untuk membuat versi production:

```bash
npm run build
npm run preview
```

## Struktur folder

```
src/
  App.tsx       konten dan komponen utama
  index.css     gaya global dan tema
  main.tsx      entry point React
  assets/       foto
public/         favicon
```
